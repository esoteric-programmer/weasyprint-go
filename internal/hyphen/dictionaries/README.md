# Hyphenation dictionaries

These are the `hyph_*.dic` hyphenation pattern files distributed with
[Pyphen](https://github.com/Kozea/Pyphen) 0.18 (which takes them from
LibreOffice), re-encoded to UTF-8 and gzip-compressed. They are used by
WeasyPrint for `hyphens: auto`.

Each dictionary keeps its original license; see the `README_hyph_*.txt`
files in this directory. Dictionaries without a README are distributed by
LibreOffice under the LGPL/MPL (most patterns are tri-licensed
GPL/LGPL/MPL).
